# Tic-Tac-Toe

Hey! This is my submission for the Hack Club Crescent Lightweight card. 

It's just a super simple Tic-Tac-Toe game built entirely in one file. No React, no external libraries, just raw HTML, CSS, and some JavaScript. 

**Size & Measurement:** 
I just checked the properties of my `index.html` file on my computer, and it sits at about 2.7 KB uncompressed. Easily under the 5 KB limit! 

**Trickery used:**
Honestly, I didn't even need to use a minifier or any crazy compression tools like UPX. Turns out if you just write vanilla code and avoid bloated frameworks, the web is naturally pretty lightweight. I had a few typos while building it (spelled it "Toee" at first lol), but everything works perfectly now.
